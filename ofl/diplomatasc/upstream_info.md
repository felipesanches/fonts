## Summary

Diplomata SC was designed by Eduardo Tunni. It was published as a single Regular weight (small capitals variant) covering Latin and Latin Extended subsets. The font file was sourced from `fonts/diplomatasc/ttf/DiplomataSC-Regular.ttf`. The same upstream repository also hosts Diplomata.
