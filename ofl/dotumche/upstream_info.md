## Summary

DotumChe was designed by HanYang I&C Co. and hosted under the googlefonts GitHub organization (same repo as Gulim and Dotum). It was published as a single Regular weight covering the Korean script alongside Cyrillic, Greek, Latin, and Latin Extended subsets. The font file was sourced from `fonts/ttf/hinted/dotumche-Regular.ttf`. Primary script is Korean.
